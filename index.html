Sejarah Linux

Linux dibuat oleh Linus Torvalds pada tahun 1991. Awalnya hanya kernel, kemudian berkembang menjadi sistem operasi lengkap.

Distribusi Linux

  • Ubuntu
  • Debian
  • Arch Linux
  • Fedora

Kelebihan Linux

  • Gratis dan Open Source
  • Aman dan stabil
  • Banyak distro dan komunitas besar
  • Ringan dan bisa dikustomisasi

Distro Populer

Ubuntu

User-friendly, banyak software, cocok untuk pemula.

Arch Linux

Rolling release, sangat bisa dikustomisasi, cocok untuk advance user.
